HAMZA AI SOLUTIONS — PORTFOLIO WEBSITE

CONTENTS
- index.html: website content and page structure
- style.css: responsive design and visual styling
- script.js: mobile navigation and current year

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open it in your browser.
   (For local development, you can also use VS Code with the Live Server extension.)

IMPORTANT — PERSONALIZE BEFORE PUBLISHING
1. In index.html, replace YOUR_EMAIL@example.com with your real business email address.
2. Update the title, service wording, and project examples if your actual services differ.
3. Add your real contact links (WhatsApp, LinkedIn, GitHub, etc.) if you want them displayed.
4. The portfolio concepts are explicitly described as concept demonstrations. Do not present them as completed client projects.
5. There are no fabricated client reviews or fake ratings on this website. Add genuine testimonials only after receiving permission from real clients.

DEPLOYMENT
This is a static HTML/CSS/JavaScript website. It can be hosted on GitHub Pages, Netlify, or any standard static web host. No backend or paid service is required for the site itself.

NOTE
Google Fonts are loaded online. If the visitor is offline, the site will use fallback fonts.
